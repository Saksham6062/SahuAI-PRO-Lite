# SahuAI PRO-Lite — Professional UI Edition

The lightweight, refined edition of **SahuAI Agent v7.2** — the same powerful AI agent with a complete professional UI overhaul. Every feature of the original app is fully preserved; this edition focuses entirely on elevating the visual experience with a cleaner, faster-feeling interface.

## 🎨 What's New in This Edition

### Design System
- **Professional typography** — Inter for UI text, JetBrains Mono for code, with refined letter-spacing and line-height for effortless reading
- **Sophisticated color palette** — deep slate neutrals with a premium indigo→violet accent gradient, tuned for both light and dark themes
- **Consistent radius scale** — 10/12/14/22px corners across buttons, cards, popovers and modals
- **Layered shadows** — subtle, modern elevation instead of heavy drop shadows

### Component Upgrades
| Component | Improvement |
|---|---|
| Sidebar | Refined header gradient, premium logo treatment with inner glow, accent-bar history items |
| Header | Frosted-glass (backdrop blur) bar with crisp border |
| Welcome screen | Gradient brand headline, polished quick-prompt cards with hover elevation |
| Composer | Premium focus ring (indigo glow), elevated shadow, smooth micro-interactions |
| Message bubbles | Refined user bubble with asymmetric radius, cleaner assistant typography |
| Popovers & modals | Rounded 16px surfaces, deeper shadows, gradient headers |
| Tables & code (runtime) | Theme-aware borders, tabular numerals, consistent code font |

### Bug Fixes
- 🐛 **Fixed dark-mode readability bug** — the welcome brand & title used inline `color:#000 !important` which made them black-on-black in dark mode. Now theme-aware everywhere.
- 🐛 Refined scrollbars, focus states and reduced-motion support

## ✅ 100% Feature Parity

All original capabilities are untouched:
- 57+ models across 18+ providers
- MCP tools, agent-swarm skills
- Web search & research modes
- File/document/image/video uploads
- Voice input & speech recognition
- Python sandbox (Pyodide) & code interpreter
- Export to PDF / DOCX / XLSX / PPTX
- Chat history, pinned messages & search
- 2000+ languages, custom instructions
- Light/dark themes, PWA support

All 166 element IDs, 129 event handlers and 32 script dependencies are preserved exactly as the original.

## 🚀 Usage

Open `index.html` in any modern browser — no build step required.
